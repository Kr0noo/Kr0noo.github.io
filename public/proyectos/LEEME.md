# Capturas de proyectos

Guarda aquí los PNG y enlázalos desde `src/data/portfolio.ts`:

```ts
{
  nombre: "ShortCAM",
  imagen: "/proyectos/shortcam.png",
  ...
}
```

Recomendación: 1600 × 1000 px aprox. (relación 16:10, que es la que usa la
tarjeta). Sin el campo `imagen` se dibuja una carátula generada con el
monograma del proyecto.
